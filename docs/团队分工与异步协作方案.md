# 校内赛三人团队分工与协作方案

## 一、 校内赛目标（能跑、能看、能交差）

校内赛核心目标是跑通闭环、拿出实物、通过答辩，不过度搞虚套路。最终交付只要三样：
1. **能演示的实物**：一个放桌上的固定基站 + 一个戴身上的穿戴小盒。
2. **直观的展示效果**：人走动有波形变化，隔墙走动有反应，模拟摔倒触发蜂鸣器报警、数码管跳变、摄像头拍张照。
3. **合格的提交材料**：一份完整图文的作品设计报告 + 一段 3 分钟演示答辩视频。

---

## 二、 三人模块包干（各管各的摊子）

### 成员 A：固定基站全包（放桌上的这一摊）
* **管辖硬件**：ESP32-S3（主控）、STM32（姿态解算）、FPGA（数码管与蜂鸣器）、SD卡、OLED屏、电源模块、面包板接线。
* **具体干啥**：
  1. 把桌上的板子插稳连好，供电做稳，别松动；
  2. S3 开热点，接收穿戴端的 UDP 数据包，顺便提取 Wi-Fi CSI 数据（无需 ESP8266）；
  3. S3 驱动 SD 卡存数据、驱动 OLED 显状态，并通过串口让 FPGA 响蜂鸣器/切数码管；
  4. 把成员 C 给出的跌倒判断规则写进 S3。
* **怎么自己测**：穿戴端不在身边时，电脑连 S3 热点用网络助手发几个假包，测通收包、存卡、OLED、板间报警全链路。

---

### 成员 B：移动穿戴全包（戴身上的这一摊）
* **管辖硬件**：ESP32-CAM + MPU6050 + 独立电池（18650盒/小充电宝）+ 绑带外壳。
* **具体干啥**：
  1. 调通 MPU6050 读取加速度和角速度；
  2. 连入基站 Wi-Fi，定时把姿态数据用 UDP 发给基站；
  3. 收到基站通知后，摄像头抓拍一张照片回传；
  4. 把设备做成能绑在身上、能带出去走动的便携小包。
* **怎么自己测**：固定站不在身边时，戴着设备在身上走走，手机/电脑连同一个 Wi-Fi 看收到的数据连不连续。
* **⚠️ 核心红线**：必须独立供电（5V/2A），严禁和固定台共用电源，否则发 Wi-Fi 拍照必死机。

---

### 成员 C：测试挑刺、定规则、交差材料全包（不焊板子，管验收交付）
* **定位**：团队质检员 + 规则制定者 + 报告与视频主编。
* **具体干啥**：
  1. **实机测试挑毛病**：自己戴上设备在基站前走动、坐下、摔在垫子上、隔门走，把“哪里误报了、哪里没反应、哪里断流了”直接提给 A 和 B 去改；
  2. **看数据定规则**：把 A 录在 SD 卡里的 CSV 数据拷到电脑（用 Python 或 Excel 画折线图），看看走路和摔倒时波形差在哪，定个判断规则（如：加速度冲击突变 + CSI随后平稳不动），把逻辑理清交给 A；
  3. **写报告**：向 A 和 B 收集原理图、实物照片和接线说明，执笔写完《作品设计报告》；
  4. **剪视频**：按演示剧本（待机 $\rightarrow$ 走动 $\rightarrow$ 隔门穿墙 $\rightarrow$ 模拟摔倒报警抓拍），拍好素材并剪出 3 分钟答辩视频。
* **怎么自己测**：拿历史数据跑跑阈值规则，对照比赛评分表逐项检查报告有没有漏项。

---

## 三、 如何异步配合（各干各的，不互相卡进度）

1. **唯一通信约定**：
   * A 和 B 只约定一个简单的 UDP 格式（如 16 字节：`包序号 + 3轴加速度 + 3轴角速度`）。
   * 格式定死后，B 只管发，A 只管收，写代码互不干涉。
2. **免等待自测（不用等人齐了再干活）**：
   * B 没做完，A 拿电脑网络助手发模拟数据测基站；
   * A 没做完，B 拿手机看自己的数据推流；
   * C 可以先搭好报告骨架、准备测试脚本，等数据一出来就分析。
3. **异步交接**：
   * A 录完数据把文件传群里，C 随时下载看；
   * B 把做好的穿戴小盒贴好开关说明放工位，A 或 C 随时拿去合体测试。
4. **拼积木交报告**：
   * A 提供基站原理介绍与实物照片；
   * B 提供穿戴端说明与佩戴照片；
   * C 负责写背景、整合成品报告并剪出视频，谁也不用给谁催进度。

---

## 四、 校内赛减负避坑要点

* **FPGA 绝不死磕**：用 AI 工具直接生成串口接收、数码管显示、蜂鸣器代码，引脚对好能响能亮即可，不搞复杂计算。
* **3 分钟演示只演 4 幕**：
  1. 静止无人（波形平稳、不报警）；
  2. 室内走动（状态切走动、波形起伏正常）；
  3. 隔门走动（直观展示 Wi-Fi 能穿墙）；
  4. 摔在垫子上（蜂鸣器大响、数码管跳、拍一张照），效果即达满分。
