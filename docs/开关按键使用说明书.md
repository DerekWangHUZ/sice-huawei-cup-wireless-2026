# 开关与按键使用说明书

> 适用对象：跌倒检测基站（ESP32-S3 + Artix-7 FPGA）的现场操作者与答辩讲解员。
> 本文只讲"怎么按、按了会发生什么"，协议与实现细节见
> [团队协作规范与接口契约.md](团队协作规范与接口契约.md) §4。

---

## 一、上电与首次使用

1. **先开基站（ESP32-S3）**，等 OLED 出现「跌倒检测基站 / 正常」。
2. **再开 FPGA 板**；本板上电后需**按一次板上 CONFIG 按钮**才会启动。
3. 上电后前 2 秒是自检：数码管 `FALL` 急闪 + 蜂鸣器三短一停 + 12 颗 LED 爆闪。
   想安静上电，**提前把 SW2（静音）拨到 ON**。
4. 自检结束后：
   - 未收到基站数据 → 数码管 `HELLO` 慢闪（正常，表示"我在等基站"）
   - 收到首帧 → 数码管 `rEAdy`，OLED 主页显示状态与接入情况

> 若按键盘完全无反应，先检查 FPGA **C14 → S3 GPIO18** 那根上行线是否插好
> （见第六节排查）。

## 二、拨码开关

| 开关 | 板上位置 | 拨到 ON 的作用 | 备注 |
|---|---|---|---|
| **SW1** | 第 1 位 | **进入演示模式**（OLED 切演示页，键盘用于选场景） | 拨回 OFF 退出演示；演示期间真实告警不抢屏 |
| **SW2** | 第 2 位 | **蜂鸣器完全静音**（含上电自检、告警） | 优先级最高，任何状态都不出声 |

- 拨码丝印从 SW1 起编号；T9 那颗是复位按键（不是拨码），不计入 SW 序列。
- SW3 及以后各位置未使用。

## 三、键盘（KEY0 ~ KEY15）

板上 4×4 矩阵键盘按丝印编号 **KEY0~KEY15**，行主序排列：

```
 KEY0   KEY1   KEY2   KEY3
 KEY4   KEY5   KEY6   KEY7
 KEY8   KEY9   KEY10  KEY11
 KEY12  KEY13  KEY14  KEY15
```

**注意：扫描起点一角是 KEY0，另一端是 KEY15**（编号与矩阵扫描顺序一致，
即恒等映射，以 `rtl/input_ctrl.v` 的 key_number() 为准）。

### 3.1 正常模式（SW1 = OFF）

| 按键 | 功能 |
|---|---|
| **KEY13** | **循环翻页**：P0 状态 → P1 遥测 → P2 系统 → P3 设置 → P4 演示 → 回到 P0 |
| **KEY14** | **进入设置页**（P3） |
| **KEY15** | 蜂鸣器开 / 关切换 |
| **KEY0**  | 回默认状态页（P0） |
| **KEY0（告警中）** | **人工解除告警**：按一次显示「人工解除?」，**3 秒内再按一次**才真正解除 |

其余键在正常模式下无作用。

### 3.2 设置页（P3 内）

| 按键 | 功能 |
|---|---|
| **KEY0**  | 光标上移一项 |
| **KEY1**  | 光标下移一项 |
| **KEY2**  | 当前项数值 **−** |
| **KEY3**  | 当前项数值 **+** |
| **KEY14** | 退出设置，回状态页 |

改动**立即保存**（掉电不丢），不需要额外确认键。

设置项共 9 项：

| # | 项 | 说明 / 推荐值 |
|---|---|---|
| 1 | CONTRAST | OLED 对比度，16 一档 |
| 2 | AUTO PAGE | 页面自动轮播 开/关（答辩时建议关） |
| 3 | CYCLE | 轮播周期 2/3/5/8/10 秒 |
| 4 | TEL RATE | 数码管遥测刷新 0.5/1/2 秒 |
| 5 | PEND BEEP | 待确认（疑似跌倒）阶段是否发提示音 |
| 6 | BUZZER | 蜂鸣器总开关（与 SW2 相"或"，任一静音即无声） |
| 7 | TONE | 蜂鸣器音调 低(2.7k)/中(3.1k)/高(4.0k) |
| 8 | FACTORY | 恢复出厂：显示 `AGAIN!` 后 **3 秒内再按一次 +** 才执行 |
| 9 | X-SHIFT | **左侧遮挡补偿**：0~4 列，默认 2。左侧边框吃掉字就加大，右侧内容不全就减小 |

### 3.3 演示模式（SW1 = ON）

| 按键 | 功能 |
|---|---|
| **KEY0** | 场景 0：**S3 全链路剧本**（需 S3 在场，自动跑 静止→行走→待确认→告警→解除） |
| **KEY1** | 场景 1：静止 |
| **KEY2** | 场景 2：走动 |
| **KEY3** | 场景 3：待确认（显示合成冲击值） |
| **KEY4** | 场景 4：告警（声光全开） |
| **KEY5** | 场景 5：**LED 逐颗走灯**（同时用来核对引脚↔丝印） |
| **KEY6** | 场景 6：数码管段码自检 → 蜂鸣器三档试听 |
| **KEY7** | 场景 7：预留 |
| **KEY8** | 下一个场景（循环） |
| **KEY9** | 场景内调参 **−**（合成读数 −0.01g；场景 6 音调降档） |
| **KEY10** | 场景内调参 **+**（合成读数 +0.01g；场景 6 音调升档） |

退出演示：**把 SW1 拨回 OFF**（不是按键）。退出后 OLED 立刻回到真实状态；
若此时真实告警仍锁存，会直接进入告警屏。

## 四、OLED 页面一览

| 页 | 标题 | 内容 |
|---|---|---|
| **P0** | 跌倒检测基站 | 32×32 中文状态词（正常/行走/疑似跌倒/跌倒告警，告警 2Hz 反色闪）+ **底部接入状态区** |
| P1 | 遥测 | 合加速度、三轴、角速度、帧率、16 柱幅值历史（数据停摆时显示 `--`） |
| P2 | 系统 | IP/信道、运行时长、SD 文件名、坏帧数、FPGA 与键盘链路、SEQ/PKT、判定参数 |
| P3 | 设置 | 9 项设置，当前项反色高亮 |
| P4 | 演示模式 | 场景名、该场景预期的声光表现、剧本进度 |

页码 `N/5` 显示在**除主页外**各页标题栏右上角。

### 4.1 主页底部「接入状态」区

- 全部正常：page6「**全部正常**」+ page7「**设备就绪**」，居中不滚动。
- 有异常：两行**横向滚动**——上行列具体原因，下行给处置建议：

| 屏上提示（原因行） | 建议行 | 含义 | 怎么办 |
|---|---|---|---|
| 穿戴端无数据 | 查穿戴端电源 | 3 秒内没收到合法姿态帧 | 检查穿戴端是否上电、是否连上 `CSI_FALL_AP` |
| 串口断开 | 查两板连线 | S3 收不到 FPGA 上行心跳 | 检查 B15/C14 与 GPIO17/18 接线、FPGA 是否已启动 |
| 键盘未连接 | 查键盘排线 | 上行链路无快照心跳 | 同上 |
| 存储卡未插入 | 插好卡后上电 | 卡未识别或挂载失败 | 插卡或重新上电 |

## 五、告警与解除

告警触发后（真实判定或演示场景 4）：

- 数码管 `FALL` 急闪、蜂鸣器三短一停、12 颗 LED 随节拍爆闪
- OLED P0 显示「跌倒告警」（2Hz 反色），底部显示冲击幅值 `X.XXg` 与
  `T+NNs` 持续时长（静音时附 `MUTE`）

**两种解除方式**：

| 方式 | 操作 | 说明 |
|---|---|---|
| **自动** | 人起身（持续活动 400ms 以上） | 无需操作，活动足够即自动解除 |
| **人工** | 按 **KEY0** → 显示「人工解除?」→ **3 秒内再按 KEY0** | 操作者显式命令，防误触；成功后大字区显示「解除」2 秒 |

人工解除后 FPGA 立即停止声光，数码管回到 `rEAdy`。
演示模式下剧本的"解除"步骤若遇上真实告警锁存，会被自动抑制（不掐断真实告警）。

## 六、常见问题排查

| 现象 | 排查顺序 |
|---|---|
| 按键完全没反应 | ① C14→GPIO18 线；② P2 系统页 `UI` 是否 `OK`；③ FPGA 是否已按过 CONFIG |
| 蜂鸣器不响 | ① SW2 是否 OFF；② 设置页 BUZZER 是否 ON；③ 设置页 TONE 换档试听 |
| 左侧文字被切 | 设置页 X-SHIFT 调大（+）；右侧内容不全则调小（−） |
| 数码管显示 `HELLO` 不消失 | 正常：表示还没收到 S3 的帧。查 S3 是否上电、B15 线是否插好 |
| 数码管显示 `------` | 待确认阶段但无有效遥测，等待下一帧或检查穿戴端 |
| 上电无任何显示 | 按一次 CONFIG 按钮（本板上电后需手动触发配置） |

## 七、关机顺序

先关穿戴端 → 再关 FPGA → 最后关基站。无特殊要求，SD 卡写入有 1 秒周期落盘，
顺手等两秒再断电更稳妥。
