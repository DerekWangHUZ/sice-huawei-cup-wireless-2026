# 基站电气接线表（成员 A）

> 对应契约《团队协作规范与接口契约.md》§5.1 第 1 项交付物（基站电气接线表）。
> 引脚常量集中在 `firmware/base_station/main/board_pins.h`，**现场改线只改那一处**，
> 其它源文件不出现裸引脚号。

---

## 1. 接线表

主控：**ESP32-S3**（ESP-IDF v6.1，target `esp32s3`）

### 1.1 与 FPGA 的板间链路

| 信号 | ESP32-S3 | 方向 | FPGA（Artix-7） | 说明 |
|---|---|---|---|---|
| UART TX | **GPIO17** | S3 → FPGA | **B15**（右扩展排母上排第 1 脚） | 115200 8N1，下行控制帧 |
| UART RX | **GPIO18** | FPGA → S3 | **C14**（右扩展排母，B15 邻位） | 115200 8N1，上行 UI 帧（拨码快照/键盘事件，1s 心跳） |
| GND | GND | — | GND（同排末位） | **必须共地** |

### 1.2 OLED 状态屏（1.3"，四脚 I2C）

| 模块脚 | ESP32-S3 | 说明 |
|---|---|---|
| GND | GND | 共地 |
| VCC | **3V3** | 3.3V；模块板载上拉 |
| SCL | **GPIO5** | I2C0，400 kHz |
| SDA | **GPIO4** | I2C0 |

- **I2C 地址**：固件启动时按 `0x3C` → `0x3D` 顺序探测，取实际应答者；
  两者都无应答则告警并禁用显示（不影响主链路）。
- **控制器**：SSD1306 与 SH1106 均支持（驱动统一走页寻址，避开 SH1106 不支持的
  水平寻址命令）。型号由 `board_pins.h` 的 `OLED_CTRL_SH1106` 选择，
  该宏已包含两者的列偏移差异。
  **本机这套模块实测为 SSD1306**（真机探测命中 0x3C、初始化序列通过），
  故 `OLED_CTRL_SH1106` 保持 `0`。

### 1.3 microSD 模块（六脚 SPI）

| 模块脚 | ESP32-S3 | 说明 |
|---|---|---|
| GND | GND | 共地 |
| VCC | **3V3** | 见 §1.4 |
| CS | **GPIO10** | 片选 |
| SCK | **GPIO12** | SPI 时钟 |
| MOSI | **GPIO11** | 主机输出 |
| MISO | **GPIO13** | 主机输入 |

- 使用 **SPI2**（`SDSPI_DEFAULT_HOST = SPI2_HOST`）；GPIO10~13 正是该外设的
  IO_MUX 默认脚，走默认脚时序最好。
- SPI 时钟默认 **20 MHz**，由 `board_pins.h` 的 `SD_MAX_FREQ_KHZ` 设定。
- 六脚模块**无卡检测（CD）脚**，固件按"挂载失败即禁用记录"处理，
  **不支持运行中拔插检测**。

### 1.4 电源

| 项 | 要求 |
|---|---|
| 逻辑电平 | **3.3V**（全部信号直连，无电平转换） |
| OLED 供电 | 3V3，约 10~20 mA |
| microSD 供电 | 3V3；写卡瞬间电流可达 100 mA 级，须与 S3 共地且供电稳 |
| 六脚模块电压 | 多数带 3.3V 稳压 + 电平转换、可用 5V 输入；**按模块丝印接线**：标 `3.3V` 的只能供 3V3，标 `5V` 的按模块说明供电（**信号侧始终为 3.3V**） |

## 2. 引脚避让清单（ESP32-S3）

改动接线前必须避开下列引脚，否则会启动失败、烧录失败或射频异常：

| 引脚 | 占用原因 |
|---|---|
| GPIO0 / 3 / 45 / 46 | strapping 脚（启动模式采样） |
| GPIO26 ~ 32 | 板载 SPI flash / PSRAM |
| GPIO19 / 20 | USB D- / D+（native USB） |
| GPIO43 / 44 | UART0 控制台（日志口） |
| **GPIO17** | 本项目 UART1 TX → FPGA |
| **GPIO18** | 本项目 UART1 RX ← FPGA 上行 UI 帧 |

GPIO11~14 被 ESP32-S3 的 SPI2 IO_MUX 复用，本设计按"默认脚复用"使用，与上表不冲突。

## 3. 改线与功能开关

| 想改什么 | 改哪里 |
|---|---|
| 任意引脚 | `main/board_pins.h`（`OLED_*` / `SD_*` 宏） |
| OLED 控制器型号 | `main/board_pins.h` 的 `OLED_CTRL_SH1106` |
| 关闭某个模块 | `main/board_pins.h` 的 `ENABLE_OLED` / `ENABLE_SD_LOG` 置 0 |
| SD 时钟 | `main/board_pins.h` 的 `SD_MAX_FREQ_KHZ` |
| 队列深度 / 落盘周期 | `main/board_pins.h` 的 `SD_LOG_QUEUE_ITEMS` / `SD_LOG_FLUSH_PERIOD_MS` |
